# Submissions

Your final answer goes in this folder, as a Pull Request.

Create **one** file here, named exactly after your GitHub username:

```
submissions/<your-github-username>.md
```

If your username is `priya-k`, the file is `submissions/priya-k.md`. The checker
compares the file name against the account that opened the Pull Request, so a
mismatch gets rejected.

Copy this format:

```markdown
# Commit Quest submission

- GitHub username: your-username
- Answer: the-phrase-you-unlocked
```

Rules the checker enforces:

- Exactly one file changed in the Pull Request.
- That file is inside `submissions/`.
- The file name matches your GitHub username.
- The answer line is present and correct.

Change anything else in the repository and it will turn you down. Get it wrong
and it will tell you what was wrong - fix the file, commit, push to the same
branch, and it re-checks the same Pull Request. You do not need to open a new
one.
