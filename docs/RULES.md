## Scoring

| | Points |
|---|---|
| Each stage cleared (6 stages, 10 each) | 60 |
| Final Pull Request, correct | 30 |
| Finished within the first 48 hours | +15 |
| Clean process | +10 |
| **Maximum** | **115** |

**Stages 1 to 6** are scored from the form. Submit each answer as you get it -
if you only submit at the end, you still get the stage points, but do it as you
go so we can see where the field is stuck and aim the hints properly.

**The final Pull Request** is scored automatically. The time it was opened is
your completion time, and it settles both the speed bonus and the ranking.

**Clean process** is the +10 for working like someone who will be pleasant to
collaborate with: commit messages that say what you did, no force-pushes over
your own history, no committing junk files, and an honest answer in the "which
commands did you use" field. Guessing your way through and admitting it scores
better than pretending you deduced it.

## Prizes

- **Top 3 fastest full completions.**
- **Furthest reached** - for the best run that did not make it to the end.
  Getting to stage 4 in your first week of Git is genuinely good.
- **Best commit message or branch name.** Entirely subjective. Be funny.

## Rules

1. **Solo.** Talk about approaches, do not hand over answers.
2. **No spoilers in public.** Do not post keys, answers or the final phrase in
   any group. Do not put them in a Pull Request title or an issue comment. This
   is the one rule that actually ruins the event for other people.
3. **Mentors help with Git, not riddles.** "How do I check out a branch" gets an
   answer. "What is the stage 4 answer" does not.
4. **One final Pull Request per person**, from your own fork, with a file named
   after your own GitHub account.
5. **Deadline is the Pull Request timestamp**, not when you solved it.

## Hints

One drop a day at noon in the help channel, each one more explicit than the
last. They are aimed at whichever stage most people are stuck on, which we read
off the form - another reason to submit as you go.

Using a hint costs you nothing. It is not a penalty and it does not affect your
score.

## Stuck, broken, or lost

Nothing you type can damage the original repository. The worst case is your own
fork getting into a confusing state, and the fix is always the same: delete the
folder, clone it again, keep going. You lose no progress, because your progress
is the answers you have written down, not the state of the folder.
