# Coding Club Website

The website for the Coding Club, IIT Patna (Dev & Open Source Division).

Static site, no build step. Open `index.html` in a browser and it runs.

## Status

Honestly, not great. Ishaan maintained this for two years and graduated in June,
and it has been sitting untouched since. There is a half-finished events page, a
gallery script that only works on one page, and a countdown timer pointing at a
fest that already happened.

It is going to get rebuilt properly this year. Before that happens, we are using
it for something else.

## Commit Quest

This repository is the map for **Commit Quest**, the Dev & Open Source
Division's onboarding hunt for freshers.

There are six riddles hidden inside this repository. Not in the website - in the
repository itself. In its history, its branches, its tags, and in the things
people deleted and thought were gone. Each riddle tells you which Git command to
run and where to look next. The last one can only be answered by opening a Pull
Request.

You do not need to know how to code. You need to be able to read, and to type
commands you are given.

**Start here:** [START_HERE.md](START_HERE.md)

Ishaan left something in the history on his way out. He was not subtle about it.
Go and read what this repository has been through:

```
git log
```

Read the messages, not just the list. One of them is talking to you.
